# Polyptych Formation

An architectural hydraulic compression scroll sequence collapsing a multi-panel photographic formation into symmetric alignment.

## Features

- **Architectural Reticle Shutter**: Converging vertical reticle guidelines on initial entry.
- **Stepped Placard Reveal**: Outside-in ink-soak title banner animation.
- **Pinned Hydraulic Scrub**: Pinned scroll timeline compressing center hero width while pulling side encroachers into symmetric composition.
- **Opposing Counter-Parallax**: Internal image translate/scale drift opposing physical row/panel compression.

## Installation

```bash
npm install @abyss-ui/core gsap
```

## Usage

```tsx
import { PolyptychFormation } from "@abyss-ui/core";

export default function MyPage() {
  return <PolyptychFormation />;
}
```
