# Rolling Gallery

An architectural vertical media stream curling into 3D space with post-process cylindrical viewport distortion, aerodynamic span camber, and Lenis smooth scroll inertia.

## Features
- **Cylindrical Post-Process FBO**: Shaders compute aerodynamic airfoil chord falloffs at viewport boundaries with zero digital tearing.
- **Dynamic Asymmetric Spreads**: 10 handcrafted editorial spreads featuring mixed aspect ratios (panoramic, 4:5, 3:2, ultra-tall spires, square anchors).
- **Embedded Ambient Video Loops**: Intersperses hardware-accelerated video loops alongside high-res photography.
- **Velocity Flex**: Critically damped second-order inertia flexes cylinder curvature seamlessly with user scroll momentum.
- **Zero-Reflow Performance**: Cached DOM layout bounds synchronized directly into Three.js world coordinates on scroll.
