# Abyss

A high-performance React component library for atmospheric WebGL shaders, kinetic scroll mechanics, interactive 3D viewports, and fluid visual transitions.

Live Showcase: [abssy.vercel.app](https://abssy.vercel.app/)

---

## Overview

**Abyss** provides production-ready, highly reactive UI components designed for editorial websites, visual portfolios, digital experiences, and interactive brand showcases. Built on raw WebGL shader pipelines, Three.js physics engines, and GSAP motion choreography, Abyss components bring tangible depth and weight to modern web interfaces.

---

## Core Capabilities & Use Cases

- **WebGL Shader Deformations**: Realtime metallic reflections, bas-relief embossing, normal map refractions, and fluid liquid distortions. Ideal for hero visuals, interactive product cards, and atmospheric backgrounds.
- **Kinetic 3D Viewports**: Volumetric 3D depth spaces, dynamic particle fields, and interactive cursor-fall physics. Perfect for visual galleries, immersive media showcases, and interactive hero headers.
- **Scroll-Driven Choreography**: Physics-based scroll triggers, path curvatures, and multi-layer parallax mechanics. Tailored for editorial landing pages, scrollytelling narratives, and showcase galleries.
- **Fluid Visual Transitions**: Seamless image morphing, clip-path masking, and elastic page transitions for interactive Web applications.

---

## Component Architecture

Abyss components are organized into four dedicated visual categories:

| Category | Description | Primary Substrate |
| --- | --- | --- |
| **Image (Shader)** | Single-pass GPU shader materials with realtime parameter controls | WebGL / Custom GLSL |
| **Gallery** | 3D depth spaces, cursor-reactive spawners, and interactive image trails | Three.js / Canvas |
| **Scroll** | Scroll-linked velocity triggers, parallax columns, and path curvature | GSAP ScrollTrigger |
| **Transition** | Multi-section clip masks, elastic path morphs, and smooth wipes | SVG / Framer Motion |

---

## Tech Stack

- **Framework**: Next.js 14 & React 18
- **Graphics & 3D**: WebGL, Three.js, React Three Fiber
- **Motion Engine**: GSAP (ScrollTrigger & Plugins) & Framer Motion
- **Styling**: Tailwind CSS
