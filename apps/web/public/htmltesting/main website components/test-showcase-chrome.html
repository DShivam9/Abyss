OVERVIEW

Arc Drift Gallery

Kinetic spatial exhibition gallery utilizing GLSL radial arc distortion curves and delta-corrected inertial physics. Designed for high-impact visual showcases with continuous focus tracking and momentum friction.

TECH & DEPENDENCIES
React 18+ Three.js / WebGL Custom GLSL TypeScript Tailwind CSS
APPLICATION & USE CASES

Ideal for portfolio specimen showcases, architecture work galleries, product landing heroes, and curated editorial archives where tactile momentum elevates presentation.

PROPERTIES
items: GalleryItem[] Array of texture sources, titles, and aspect ratios.
curvature: number (0.1 - 1.0) GLSL radial arc distortion coefficient. Default 0.42.
inertia: number (0.5 - 0.99) Momentum friction deceleration factor. Default 0.92.
dragSensitivity: number Pointer kinetic displacement multiplier. Default 1.25.
onSelect?: (item: GalleryItem) => void Event callback triggered when a card enters active focus.
ENGINEERING NOTES
• Zero layout thrashing: uses GPU vertex displacement shaders.
• Frame-rate independent physics with delta-time smoothing.
• Automated WebGL texture mipmap compression and buffer disposal on unmount.
HERITAGE & DISCLAIMER

Crafted as an independent design recreation study exploring spatial web primitives. Built from scratch with custom math, shaders, and physics. Not affiliated with original inspiration works.

INSTALLATION
npm i @abyss-ui/core
BASIC USAGE
import { ArcDriftGallery } from "@abyss-ui/core";

export default function SimpleGallery() {
  return (
    <ArcDriftGallery
      items={galleryItems}
      curvature={0.42}
      inertia={0.92}
    />
  );
}
CONTROLLED STATE
import { useState } from "react";
import { ArcDriftGallery } from "@abyss-ui/core";

export default function ControlledGallery() {
  const [activeId, setActiveId] = useState("01");

  return (
    <ArcDriftGallery
      items={galleryItems}
      activeId={activeId}
      onSelect={(item) => setActiveId(item.id)}
    />
  );
}
